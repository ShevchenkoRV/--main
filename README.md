# Система тестування студентів

Курсовий проєкт для автоматизації процесу тестування студентів.  
Адміністратор створює та редагує тести, студенти проходять їх і одразу бачать результати.

---

## Можливості

**Для адміністратора**
- Вхід за паролем
- Створення тестів з питаннями та варіантами відповідей
- Редагування та видалення тестів
- Імпорт / експорт тестів у форматі JSON
- Перегляд статистики по кожному студенту

**Для студента**
- Вибір тесту зі списку
- Проходження тесту з миттєвим відображенням результатів
- Таблиця відповідей з підсвіткою правильних і неправильних

## Структура проєкту

```
my_app/
├── main.py              # Точка запуску, головне вікно та навігація між екранами
├── config.py            # Стилі, шрифти, кольори
├── database.py          # Ініціалізація SQLite та створення таблиць
├── test_manager.py      # Всі запити до бази даних
│
├── frames/              # Екрани інтерфейсу
│   ├── base_frame.py        # Базові класи (BaseFrame, SelectionScreen)
│   ├── main_menu.py         # Головне меню (вибір ролі)
│   ├── admin_menu.py        # Панель адміністратора
│   ├── test_constructor.py  # Створення нового тесту
│   ├── edit_test.py         # Редагування існуючого тесту
│   ├── export_test.py       # Експорт тесту в JSON
│   ├── student_menu.py      # Вибір тесту студентом
│   ├── test_taking.py       # Проходження тесту
│   ├── results_screen.py    # Відображення результатів
│   └── student_stats.py     # Статистика студентів
│
└── testing_system.db    # База даних (створюється автоматично при першому запуску)
```

## Запуск

### Варіант 1 — готовий .exe (без встановлення Python)

1. Відкрийте папку `release/`
2. Запустіть `TestingApp.exe`

### Варіант 2 — через Python

1. Встановіть [Python 3.11+](https://python.org)
2. Встановіть залежності:
   ```
   pip install ttkbootstrap tkfontawesome
   ```
3. Запустіть програму:
   ```
   python main.py
   ```

> База даних `testing_system.db` створюється автоматично при першому запуску.
